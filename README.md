# ANIMACIÓN DE NAVIDAD

# Descripción
Esta animación creada con Tkinter y canvas trata sobre una árbol de navidad que se ve construyendo
mientras se recorrenciertas animaciones adicionales como:
- Papá Noel en el trineo
- Regalos de navidad.

# Instalación
1. Clonar el repositorio.
2. Ejecutar el programa ´python arbol_particulas.py´
